# 모덕 달리기 — 삼락 벚꽃길

`index.html`을 브라우저에서 열면 실행됩니다. 같은 폴더의 스크립트, 스타일과 assets 폴더를 유지하세요.

## 게임 방법

시작 화면에서 **1P 혼자 달리기** 또는 **2P 함께 경쟁**을 선택합니다. 1P 캐릭터를 고르면 2P는 다른 학교 캐릭터를 사용합니다.

| 선수 | 왼발 / 오른발 | 점프 |
| --- | --- | --- |
| 1P | ← / → | Space 또는 ↑ |
| 2P | A / D | W |

두 발을 번갈아 누르세요. 같은 발을 연속으로 누르거나 길게 누르면 새 발걸음으로 인식하지 않습니다. 화면 버튼으로도 조작할 수 있습니다. 혼자 할 때는 A/D/W도 사용할 수 있습니다.

2인 경기는 화면을 좌우로 나누며 각 선수의 속도에 따라 배경과 장애물이 따로 움직입니다. 두 선수에게 같은 위치의 꽃과 장애물이 주어집니다. 선택한 거리(100·150·200미터)에 먼저 도착하면 승리하고, 90초가 지나면 더 멀리 달린 선수가 승리합니다. 같은 기록이면 무승부입니다. 꽃 4송이마다 3초 부스터가 적용됩니다.

점프는 항상 사용할 수 있습니다. 장애물 도전을 켜면 고깔이 등장하며 부딪히면 감속합니다. 점프 중에는 다시 점프할 수 없습니다. P 또는 Esc로 잠시 멈춥니다. 다른 창으로 이동하면 자동으로 멈춥니다.

## 메이키 메이키 연결

1P 발판은 LEFT ARROW / RIGHT ARROW, 점프 버튼은 SPACE에 연결합니다. 2P 발판은 뒷면 A / D, 점프 버튼은 W에 연결합니다. 각 참가자가 EARTH 접지를 접촉해야 합니다. 실제 연결 및 동시 입력은 기기에서 확인하세요.

발을 떼면 입력이 해제되는 구조로 만드세요. 점프는 별도 버튼 입력이며 양발을 떼는 동작을 감지하지 않습니다.

## 캐릭터와 배경

원본 `결과물.png`는 보존했습니다. `assets/mascots.png`는 4열 × 2행 캐릭터 시트이며, `assets/motion.png`는 각 캐릭터의 달리기 6장·대기·점프를 담은 8열 × 2행 시트입니다. 부드러운 가속과 감속, 중력 기반 점프를 사용합니다.

`assets/samnak-cherry.png`는 삼락 벚꽃길 분위기를 참고한 실사풍 생성 이미지입니다. 실제 촬영 사진은 아닙니다. 카메라를 높은 위치에서 내려다보도록 수정해 앞쪽 길을 넓게 확보했습니다. 장애물에는 큰 주황 고깔, 밝은 테두리, 그림자와 접근 시 점프 표시를 적용했습니다.

사진 배경은 달린 거리에 따라 반복 확대와 부드러운 전환을 사용해 전진하는 느낌을 표현합니다. 실제 길을 연속 촬영한 영상은 아닙니다. 기본 2px 흐림을 적용하며 캐릭터와 장애물은 선명하게 유지합니다. 이전 배경은 `assets/samnak-cherry-eye-level.png`에 보관했습니다.

시작 화면의 **배경 사진과 흐림 조절**에서 0~5px 흐림을 조정하거나 JPG/PNG를 선택할 수 있습니다. 선택한 사진은 현재 브라우저에서만 사용하고 외부로 전송하지 않습니다.

## 그림 생성 지시 요약

내장 이미지 생성 도구로 학교 캐릭터의 노란 꽃 장식·붉은 땋은 머리·분홍 옷, 초록 산 모자·흰 정상·연두 셔츠·파란 바지를 유지한 투명 캐릭터 시트를 제작했습니다. 검은 외곽선과 약간의 입체적인 명암, 일정한 크기와 기준선, 연속 달리기 자세를 요청했습니다.

배경 생성 지시: 부산 삼락 낙동강 제방 벚꽃길의 분위기를 참고한 봄날의 벚꽃터널, 중앙으로 이어지는 빈 회색 산책로, 연분홍 꽃과 자연광, 사람·문자·게임 화면 제외. 수정 지시: 카메라를 약 3m 높이로 올려 아래를 내려다보며, 소실점을 중앙 위쪽에 두고 앞쪽 길을 넓게 확보합니다.

## 확인

`node tests/game.test.cjs`로 선수별 이동과 점프, 입력 분리, 승리·무승부·시간 종료, 동일한 장애물, 일시정지, 착지, 배경 확대와 분할 화면을 확인할 수 있습니다.

실사풍 결승 아치: assets/finish-arch.png. 내장 이미지 생성 도구로 제작한 투명 배경의 크림색·벚꽃색 공기 주입식 아치이며 FINISH 글자, 실제 천의 봉제선과 자연광 명암을 요청했습니다. 결승에서는 화면 길 폭에 맞춰 커지고, 체크무늬 결승선이 바닥에 표시됩니다. 캐릭터 크기는 약 18% 늘렸습니다.



시작 화면에서 100·150·200미터를 선택합니다. 기본 거리는 150미터입니다. 나리는 꽃 캐릭터, 산이는 산 캐릭터입니다. 게임 안내와 결승 표시를 한글로 정리하고 글자를 키웠습니다. Noto Sans KR 가변 글꼴을 로컬로 포함하며 SIL Open Font License는 assets/fonts/OFL.txt에 있습니다.
